# Steps to Run Locally 

### 1. Clone this Repository
```
# HTTPS
git clone https[://github.com/iAhmadTaj/IAhmadTaj.github.io.git]

```

### 2. Environment
```
cp .env.example .env
```
## Edit `.env.local` to Add Required Secrets

### 3. Install Dependencies
```
pnpm install
```

### 4. Start Dev Server
```
pnpm dev
```     

### 5. Build for Production
```
pnpm build
```
